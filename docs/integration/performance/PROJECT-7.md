# WORKS 详情内切换与展开性能 · project-7

同一 PR #15 / integrate-approved-portfolio；不合并 main，不新增作品资料。基线为 9fce2c7。保留轮盘几何、惯性/吸附及 800ms 共享封面展开/收回，不靠缩短动画隐藏耗时。

## 实际发现

- CDP Timeline/CPU采样的基线里，`build → targetRect → getBoundingClientRect` 首次强制布局有一次 42.844ms 墙钟记录（该事件线程 CPU 6.509ms，云主机调度会影响墙钟）。几何读数发生在构建阶段，没有发现每帧反复测量布局。
- 原来每次打开都创建详情 iframe、执行脚本/建立播放器，关闭后删除；共享图层先深拷贝整个五卡轮盘再删除四张。没有将卡顿无证据归咎于视频：当前作品数据没有视频。
- 没发现详情打开后轮盘持续高负载的原因；已有 suspend 机制保留。没有新增 blur、backdrop-filter、视频自动播放或整屏滤镜。

## 变更

- WORKS 就绪后的空闲阶段预热一次详情文档/CSS（不带作品 ID、不请求封面或视频）。保留一个隐藏、inert、无动画循环的详情 iframe；打开只更新内容，关闭释放视频后隐藏。若点击早于预热，沿同一加载 Promise 等待，无第二个播放器。
- 共享图层只复制选中卡片及必要的 3D 祖先。几何只在展开/收回前批量测量，保持原路径与时长；不强行删掉真实曲面分片。
- 新增独立的上一部/下一部双语折角控件、序号；顺序直接来自 projects-data.js。现有两栏布局不移动，桌面控件放在原底部留白，手机放在视频之后正常流中。
- 约360ms横移12px和淡出/淡入，原地复用信息与唯一video节点；期间锁定重复输入。减少动态效果和无WAAPI时直接更新。
- 切换更新当前详情 URL（replaceState，不堆积逐部历史）、sessionStorage及暂停中的轮盘。X或浏览器后退返回最后浏览的作品；前进可重新打开该作品。直接详情URL也可循环切换，关闭回WORKS。
- 首次播放前不设置video.src，preload=none；用封面/poster或原比例占位。主动播放才赋源并播放。切换开始暂停旧视频，换片/关闭时移除src并load()释放引用；播放失败提示并保留浏览其他作品能力。兼容现有video字符串里的相对路径或外部HTTPS媒体URL，不绑定本地大文件；没有新增外部嵌入播放器服务。

## 同条件浏览器样本

Chromium，1440×900和390×844，各版本每尺寸10次打开/关闭；WORKS停稳约700ms后开始，更新版已可空闲预热。无CPU节流，云端软件GPU；不是实际手机硬件。采样用PerformanceObserver长任务、root rAF间隔、CDP Performance和HeapProfiler。点击响应从浏览器内自动化发起点击的采样点到opening状态，包含输入派发开销，不是精确Event Timing输入延迟。主线程TaskDuration覆盖点击至open，窗口长度随实际调度变化。

| 指标 | 桌面基线 → 更新 | 手机视口基线 → 更新 |
| --- | --- | --- |
| 首次点击到opening | 108.5 → 53.6ms | 88.6 → 28.4ms |
| 后9次点击到opening中位数 | 62.3 → 21.6ms | 68.4 → 21.3ms |
| 展开窗口TaskDuration中位数 | 134.2 → 95.7ms | 140.6 → 92.5ms |
| 十轮rAF间隔>50ms的数量 | 11 → 12 | 0 → 0 |
| 最大rAF间隔 | 166.7 → 83.3ms | 33.3 → 33.3ms |
| 样本记录的>50ms长任务 | 0 → 0 | 0 → 0 |

不能把长任务为0解读为没有掉帧。桌面长帧数量未改善，仍受软件GPU/合成及云主机调度影响；不宣称稳定60FPS或已消除全部卡顿。主要可验证的收益是打开前的等待和脚本工作减少。

## 内存与资源

缓存策略会保留一个详情文档，更新版十次开关后的堆约7.06MB（十进制），高于基线约5.96MB；不是整体内存降低。另一次每轮包含三次详情切换的十轮测试，强制GC后JS堆从第1轮6,901,892B增至第10轮7,305,420B（约+0.38MiB）；11个documents、784个nodes、405个监听器各轮保持相同。此样本仍有小幅堆增长，不能据此证明完全没有泄漏或长期内存恒定；未测GPU显存和完整浏览器RSS。临时测试脚本、完整trace、生成的视频不提交。

## 功能验收

- 1440×900、390×844、320×568：每尺寸十轮打开→详情连续切三部→X关闭，轮盘保持最后ID和同一实例；循环首尾、直接详情、前进后退通过。
- 最终缓存版复测切换中后退、前进、关闭后滚轮、窗口变化、快速历史、减少动态效果、关闭WAAPI的回退；共享图层三个尺寸起终点误差<0.1px。
- 临时路由注入测试数据（未改仓库数据）：进入WORKS及详情均为0个MP4请求；主动点击后播放生成的H.264 MP4，画框高度不变；换片移除旧src、外部404提示可恢复、关闭后无src且始终只有一个video。
- ABOUT模块展开/关闭、CONTACT对焦与返回HOME、右侧章节导航回归。没有更改HOME泡泡、ABOUT布局/路径或CONTACT动效源文件。
- 手机为Chromium触屏仿真，未测试真实手机、Safari/Firefox，也未验证未来真实长视频的带宽/解码性能。
